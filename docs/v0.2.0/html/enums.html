enums 

All the enumerated types, collected in one place so that auto-completion can list them.

Since configuration.edges_style = <TAB> does not offer the valid values (no IDE infers the type of the assignment target), the practical way to discover them is somegraphspy.enums.<TAB> for the types, and then .<TAB> again for the values of the chosen one. The same types are also available directly, e.g. somegraphspy.LineStyle .

class somegraphspy.enums. DistributionStyle ( value ) [source] 

The style used to show a distribution. See the Julia documentation for details.

CurveDistribution = 'CurveDistribution' 

Show the density of the distribution as a curve.

ViolinDistribution = 'ViolinDistribution' 

Show the density of the distribution as a symmetric violin.

BoxDistribution = 'BoxDistribution' 

Show the quantiles of the distribution as a box.

BoxOutliersDistribution = 'BoxOutliersDistribution' 

Show the quantiles of the distribution as a box, with the outlier values.

CurveBoxDistribution = 'CurveBoxDistribution' 

Show both a curve and a box.

ViolinBoxDistribution = 'ViolinBoxDistribution' 

Show both a violin and a box.

HistogramDistribution = 'HistogramDistribution' 

Show the distribution as a histogram.

CumulativeDistribution = 'CumulativeDistribution' 

Show the cumulative distribution.

class somegraphspy.enums. HeatmapLinkage ( value ) [source] 

The linkage used when clustering the rows or columns of a heatmap. See the Julia documentation for details.

SingleLinkage = 'SingleLinkage' 

Use the minimal distance between the clusters.

AverageLinkage = 'AverageLinkage' 

Use the average distance between the clusters.

CompleteLinkage = 'CompleteLinkage' 

Use the maximal distance between the clusters.

WardLinkage = 'WardLinkage' 

Use Ward’s minimal variance.

WardPreSquaredLinkage = 'WardPreSquaredLinkage' 

Use Ward’s minimal variance on the pre-squared data.

class somegraphspy.enums. HeatmapReorder ( value ) [source] 

How to reorder the rows or columns of a heatmap. See the Julia documentation for details.

RCompatibleHclust = 'RCompatibleHclust' 

Cluster the data the same way R does.

OptimalHclust = 'OptimalHclust' 

Cluster the data using an optimal ordering of the tree.

ReorderHclust = 'ReorderHclust' 

Cluster the data and reorder the tree.

SlantedHclust = 'SlantedHclust' 

Cluster the data and slant the tree.

SlantedPreSquaredHclust = 'SlantedPreSquaredHclust' 

Cluster the pre-squared data and slant the tree.

SlantedOrder = 'SlantedOrder' 

Slant the data without computing a clustering tree.

SlantedPreSquaredOrder = 'SlantedPreSquaredOrder' 

Slant the pre-squared data without computing a clustering tree.

SameOrder = 'SameOrder' 

Use the same order as the other dimension.
