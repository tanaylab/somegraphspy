sources 

Data source views into the graphs. See the Julia documentation for details.

A view bundles the parts of a graph that one source of data fills: the values of one role, the entities they belong to, and the configuration they are shown by. The views are obtained from a graph by its ..._fields methods (e.g., graph.x_axis_vector_fields() ), which mirror the Julia accessor functions. A source is any Python function writing into a view. It works on any graph and any role that offers the same kind of view. The views hold no data of their own. They reference the graph’s own objects, so writing into them changes the graph.

class somegraphspy.sources. PartFields ( jl_obj : Any ) [source] 

A data source view of one part of a graph built from several such parts (a series of bars, a line, a distribution), identified by its (1-based) index in the graph . See the Julia documentation for details.

The fields of the part’s data (its name , hover , color , …) are also fields of the view, and so is its entities , whatever the part calls them (the bars of a series, the points of a line). The roles of the part are AxisVectorFields views along the matching axis of the graph: the values of a series of bars or a distribution, the x and y of a line.

graph : Any 

The graph the part belongs to.

index : int 

The (1-based) index of the part in the graph.

data : Any 

The part itself (a SeriesData , a LineData , a DistributionData ).

entities : VectorEntitiesData 

The entities of the part, shared by all its roles.

values : VectorFields 

The view of the values of the part (of a series of bars or a distribution).

x : VectorFields 

The view of the X coordinates of the part (of a line).

y : VectorFields 

The view of the Y coordinates of the part (of a line).

class somegraphspy.sources. VectorFields ( jl_obj : Any ) [source] 

A data source view of one role of a graph whose entities are a vector: the data and the configuration . See the Julia documentation for details.

A function writing into such a view fills the role from some source of data, and works the same on the X coordinates of points, the values of bars, the colors of either, and so on. The configuration says what kind of view this is: an AxisConfigurationFields for values shown along an axis ( AxisVectorFields ), a ColorsConfigurationFields for values shown as colors ( ColorsVectorFields ), or a SizesConfigurationFields for values shown as sizes ( SizesVectorFields ).

data : VectorDataFields 

The values of the role and the entities they belong to.

configuration : AxisConfigurationFields | ColorsConfigurationFields | SizesConfigurationFields 

How the values are shown.
